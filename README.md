# Netflix Indonesia Landing Page
Website ini adalah clone sederhana halaman Netflix. Isinya berupa hero section, lima poster trending, beberapa card, FAQ, form email, pilihan bahasa, dan modal detail film. Semua fitur hanya simulasi frontend tanpa login atau backend.

## Materi yang Dipakai

HTML digunakan untuk membuat struktur halaman, seperti navbar, form, gambar, tombol, section, FAQ, dan footer. Kodenya ada di `index.html`.

CSS plain digunakan untuk mengatur warna, ukuran, jarak, posisi, Flexbox, Grid, Box Model, dan tampilan responsive untuk desktop, tablet, dan mobile. Kodenya ada di `style.css`.

JavaScript digunakan untuk membuat poster film secara dinamis dengan DOM. JavaScript juga digunakan untuk event listener pada poster, modal, FAQ, tombol refresh, form email, tombol masuk, dan dropdown bahasa. Kodenya ada di `script.js`.

Array digunakan untuk menyimpan data film. Function digunakan untuk membuat kartu film, membuka modal, memeriksa form, dan mengganti bahasa. `if` digunakan untuk validasi email, sedangkan `forEach` digunakan untuk menampilkan beberapa film dan membaca beberapa elemen halaman.

Materi CSS seperti Flexbox dan Grid dapat dilihat pada bagian navbar, form, daftar poster, kartu benefit, dan footer. Media query digunakan di bagian bawah `style.css` supaya tampilan menyesuaikan tablet dan mobile.
